# 資源循環機構 — DOMドット絵プロトタイプ

Canvasや外部ライブラリを使わず、HTML/CSS/JavaScriptだけで動く地下資源処理ゲームです。

## 起動

`index.html`をブラウザで開くか、VS CodeのLive Serverで起動してください。

## 操作

- `↑ ↓ ← →`: 作業員の移動・方向転換
- `D`: 正面の岩盤を掘削。鉱石または生体廃棄物に正対している場合は採掘／回収
- `R`: 正面の坑道へ原油精製機を設置（燃料4.0）
- `M`: 正面の坑道へ鉱石精錬機を設置（燃料6.0）
- `E`: 正面の精錬機へ携行鉱石を搬入
- `P`: 正面の坑道へ生体処理機を設置（燃料10.0）
- `Q`: 正面の生体処理機へ運搬生体資源を搬入
- `B`: 携行鉱石1個で正面の坑道に粗鉱壁を設置
- `S`: 金属1.0で正面の坑道に強化隔壁を設置
- `G`: 燃料1.0を掘削電力6.0へ変換
- `Space`: 一時停止／再開

作業員は基地から連続した坑道と設備だけを移動できます。岩盤掘削は深さと密度に応じて電力を消費します。

「同区画で再挑戦」は現在表示中のシードを保ちます。「新しい区画」はシードを切り替えて資源配置を生成し直します。

油田、鉱脈、生体層は区画シードに基づいてランダムに配置され、掘り当てるまで隠れています。坑道の縁の色から油徴・鉱物反応・生体兆候を読み取れます。油田を掘ると原油が噴出し、生体層を掘ると廃棄物が坑道へ広がり始めます。

## 資源循環と目標

- 原油精製で燃料を生産
- 燃料で鉱石精錬機を設置・稼働し、金属と触媒を生産
- 生体廃棄物を`D`で回収し、処理機の前で`Q`を押して搬入
- 生体処理は1単位あたり燃料0.8と触媒0.45を消費
- 生体廃棄物を5.0単位処理し、COREを稼働状態に保つと区画制圧
- COREへ原油や生体廃棄物が到達すると耐久が減少

粗鉱壁は一時的な防壁、金属製の強化隔壁は高耐久の防壁です。圧力で損耗し、危険な状態では点滅、破壊されると坑道へ戻ります。未採掘の鉱脈も天然の壁として機能します。

## 構成

- `game.js`: 入力、ゲーム進行、マップ表示
- `world.js`: シード付きの油田・鉱脈・生体層生成と兆候
- `industry.js`: 原油・鉱石・生体の処理系
- `defense.js`: 防壁の耐久と崩壊
- `style.css`: DOMセルのドット絵表現

## 検証

Node.jsがあれば `node --test tests/systems.test.js` で資源生成、流体、精錬、バイオ処理、防壁、終了条件を検証できます。
