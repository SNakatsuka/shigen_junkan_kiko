# 資源循環機構 - MVP

ブラウザだけで動く、素のHTML/CSS/JavaScript製プロトタイプです。

## 実装済み
- クリックで地盤を掘削
- 石油源から一定間隔で石油が発生
- 石油は坑道を下方向優先で移動
- 精製機に入ると石油が消え、燃料 +1
- COREに入ると耐久値減少
- CORE耐久値が0になるとゲームオーバー
- 再稼働ボタン

## 起動
`index.html` をブラウザで開くだけです。

ローカルサーバーを使う場合:

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。
