# 資源循環機構 — DOMドット絵プロトタイプ

Canvasや外部ライブラリを使わず、HTML/CSS/JavaScriptだけで動く地下資源処理ゲームです。

## 起動

`index.html` をブラウザで開いてください。VS CodeのLive Serverでも動作します。ビルド作業やサーバーは不要です。

## 操作

- `↑ ↓ ← →`: 作業員の移動・方向転換
- `D`: 向いている方向の岩盤を掘削
- `R`: 向いている方向の空き坑道へ精製機を設置（燃料4.0）
- `S`: 向いている方向の坑道を封鎖（燃料1.0）
- `G`: 燃料1.0を掘削電力6.0へ変換
- `Space`: 一時停止／再開

作業員はCORE側の基地と、そこからつながった坑道内だけを移動できます。離れた岩盤を直接クリックして掘ることはできません。掘削は深さと岩盤密度に応じて掘削電力を消費します。初期電力を使い切る前に油田と精製機を接続してください。

油田は岩盤内に隠され、区画生成ごとに位置が変わります。坑道上端の色で「微弱・油徴・強振」の地質兆候を読み、油田を探してください。油田そのものを掘ると原油が噴出します。

## 現在の実装

- 42×28の細密DOMグリッド
- 基地から連続して掘り進むキーボード操作の作業員
- 油田ごとの圧力、最大流量、埋蔵量
- シード付きの制約付きランダム油田配置
- 掘削済み坑道に現れる3段階の地質兆候
- 初期電力内で低圧油田へ到達できる生成保証
- セル単位の連続油量と圧力差・重力による移動
- 背圧による油田産出量の低下
- 深度・岩盤密度で変化する掘削コストと掘削電力
- 処理上限を持つ精製機
- COREへの漏油と耐久ダメージ
- CSSだけで描く岩盤、坑道、油面、設備のドット絵
