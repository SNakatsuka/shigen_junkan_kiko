# 資源循環機構 — DOMドット絵プロトタイプ

Canvasや外部ライブラリを使わず、HTML/CSS/JavaScriptだけで動く地下資源処理ゲームです。

## 起動

`index.html` をブラウザで開いてください。VS CodeのLive Serverでも動作します。ビルド作業やサーバーは不要です。

## 操作

- 左クリック／ドラッグ: 選択中のツールを使用
- `1`: 掘削
- `2`: 精製機（燃料4.0）
- `3`: 封鎖材（燃料1.0）
- `Space`: 一時停止／再開
- 右クリック: 掘削ツールへ戻る

掘削は深さと岩盤密度に応じて掘削電力を消費します。初期電力を使い切る前に油田と精製機を接続してください。精製後は燃料1.0を掘削電力6.0へ変換できます。

油田に隣接する岩盤を掘ると原油が噴出します。坑道を精製機へつなぎ、COREへの流入を避けてください。

## 現在の実装

- 42×28の細密DOMグリッド
- 油田ごとの圧力、最大流量、埋蔵量
- セル単位の連続油量と圧力差・重力による移動
- 背圧による油田産出量の低下
- 深度・岩盤密度で変化する掘削コストと掘削電力
- 処理上限を持つ精製機
- COREへの漏油と耐久ダメージ
- CSSだけで描く岩盤、坑道、油面、設備のドット絵
