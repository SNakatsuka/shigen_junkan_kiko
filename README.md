# 資源循環機構 - Flow / Pressure MVP

石油を「駒」ではなく連続量として扱う版です。

## 今回の変更
- 各坑道セルが浮動小数点の石油量を持つ
- 石油は隣接セルとの圧力差で移動
- 下方向には重力ヘッドを加える
- 油田ごとに `pressure`, `maxOutput`, `reserve` を持つ
- 坑道側の背圧が高いと油田の産出量が落ちる
- 精製機には処理流量上限がある
- COREへの漏入量は周辺坑道の圧力に比例
- セル内の油量を液面表示
- 油があるセルに簡易圧力値を表示

## 主な調整値

```js
const CONDUCTANCE = 0.22;
const GRAVITY_HEAD = 0.20;
const MAX_EDGE_FLOW = 0.24;
const REFINERY_RATE = 0.16;
```

油田差は `this.oilFields` で調整できます。

厳密な流体力学ではなく、ゲームとして
「高圧から低圧へ流れる」「下へ行きやすい」「詰まると背圧が上がる」
を表現するモデルです。
